# Day 90:  Disappearing Text Writing App

Project from 100 [Days of Code by Angela Yu](https://www.udemy.com/course/100-days-of-code)

It's an app that forces you to keep typing or your text is lost. Inspired by [Most Dangerous Writing App](https://www.squibler.io/dangerous-writing-prompt-app).
